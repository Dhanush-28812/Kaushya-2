# Team Kaushya website

Static site for GitHub Pages. No build step.

## Publish
1. Create a public repository and upload all files here (index.html, style.css, script.js, .nojekyll, README.md).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Your site appears at https://USERNAME.github.io/REPO/ in a minute or two.

## Edit before publishing
- index.html: replace `your-email@example.com` in the Contact section.
- script.js: the Vidura simulation uses made-up thresholds (1.5 g, spread 25). Change them to match your prototype.
- Add team member names and photos in a new section if you like.
